Execução e publicação

● Agendamento configurado: a cada 5 horas

O bot gera arte com a OpenAI, hospeda a imagem no GitHub Pages e publica diretamente pela Instagram Graph API. O Make não é necessário.

Ver execuçõesAbrir GitHub Actions

Configuração necessária

  • OPENAI_API_KEY: geração de arte e legendas.
  • IG_ACCESS_TOKEN: token Meta/Instagram com permissões adequadas.
  • IG_USER_ID: ID numérico da conta profissional do Instagram.
  • IG_GRAPH_VERSION (opcional): versão da Graph API.

Configure em GitHub → Settings → Secrets and variables → Actions. Nunca cole chaves neste painel.
